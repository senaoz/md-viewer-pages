Moodle Performance in Türkiye — Cloudflare Analysis

Site: edu.oihs.ca Period analysed: 21–28 October 2026 Date: 28 October 2026

1. Executive Summary

Users in Türkiye have reported slow page loads on Moodle. Cloudflare traffic data for the past week points to three main causes:

  1. Distance to the serving location. Türkiye generates 62% of all requests, yet only about 10% of Turkish requests are served from Cloudflare locations in Türkiye (Istanbul, Izmir). The majority are served from Amsterdam, London, Frankfurt and Sofia. Canadian users, by comparison, are 87% served locally from Toronto.
  2. Frequent trips to the origin server. The Moodle server is hosted in Frankfurt (Hostinger). 63% of Turkish requests are not answered from Cloudflare's cache and travel all the way to the server. Some static theme files are never cached because no cache rule exists for them.
  3. Oversized files. A 3.3 MB animated loading GIF, banner images of about 4 MB each, and a 1.2 MB JavaScript bundle add significant load time, especially on slower connections.

Server resources are not the bottleneck. The slowness is mainly a combination of network distance, number of uncached requests and file size.

5.1 Proposed Cache Rule

  • Name: Moodle revisioned theme/JS assets
  • Applies to: requests to edu.oihs.ca whose path starts with one of:
    • /theme/styles.php/
    • /theme/yui_combo.php
    • /lib/javascript.php/
    • /lib/requirejs.php/
    • /theme/image.php/
    • /theme/font.php/
  • Cache eligibility: Eligible for cache
  • Edge TTL: Use the origin's Cache-Control header
  • Browser TTL: Respect origin
  • Cache key: Default; the query string is kept, which yui_combo.php requires

Rationale. These URLs contain Moodle's theme/JavaScript revision number, and Moodle already marks them as public, immutable with a 90-day lifetime. When caches are purged in Moodle, the revision number and therefore the URLs change, so stale content cannot be served.

Status: Prepared. It will be applied once an API token with Cache Rules edit permission is available.
